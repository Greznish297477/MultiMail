# Журнал изменений

## 1.2.11

- Версия в разделе «О приложении» теперь автоматически берётся из текущей сборки.
- При отсутствии пароля IMAP/POP3 остаются доступны меню, разделы и управление ящиками.
- Улучшены жест и анимация нижней навигации: направление перелистывания соответствует движению пальца.

## 1.2.10

- Добавлен выбор протокола IMAP или POP3 при подключении почтового ящика.
- Пароль приложения стал необязательным при добавлении: ящик можно сохранить и указать пароль позже.
- Для POP3 добавлено чтение входящих писем; серверные папки и действия доступны через IMAP.

## 1.2.9

- Добавлен встроенный вход Google для создания пароля приложения на Huawei/microG.
- Исправлены цвета текста на первом экране приложения.

## 1.2.8

- Добавлен отдельный способ подключения Gmail по IMAP для Huawei и microG.
- Улучшено сообщение об ошибке Google/microG с кодом 8.

## 1.2.7

- Обновлён экран первого добавления почты.
- Добавлено восстановление входа Google при ошибке Google Play Services (код 8).

## 1.2.6

- Убрана белая вспышка при первом запуске в тёмной системной теме.
- Исправлена ложная отмена входа Google.

## 1.2.5

- Исправлен вход через Google и выбор нужного Google-аккаунта.
- Добавлены понятные сообщения об ошибках Google Sign-In.
- Экран добавления почты адаптирован под тему и системные цвета.
- Улучшено обновление приложения и нижняя навигация.

## 1.2.1

- Исправлена автоматическая сборка готового APK в GitHub Actions.
- GitHub Release создаётся после успешной сборки подписанного APK.

## 1.1.0

* Собственная нижняя навигация-пилюля с анимированным индикатором.
* Свайп и нажатие для переключения нижних вкладок.
* Режим Liquid Glass и дополнительные настройки интерфейса.
* Письма не исчезают при быстром переключении ящиков.
* Добавлена проверка новых релизов на GitHub.

## 1.0.0

* Первый выпуск MultiMail: Gmail и IMAP, несколько аккаунтов, отправка писем и настройка интерфейса.
